# Banco de Formulación v2 — el prototipo de referencia

**Copia del 2026-09-25** del [Banco de Formulación](https://github.com/smortenax/perfumeria-lab/blob/master/herramientas/README.md)
del laboratorio, la herramienta HTML que el usuario usa a diario. El original sigue en el
laboratorio hasta que la app lo sustituya; esta copia es **referencia de concepto**, no
código a reutilizar tal cual.

**Lo que el usuario quiere conservar del concepto:** el trabajo en miligramos, la barra de
añadir con el buscador, la biblioteca lateral, los gráficos de reparto y pirámide, el
historial en un cajón y las bases que no pierden decimales. **Lo que cambia** está en las
[decisiones](../../decisiones.md): la barra de cuatro zonas (§4), la edición libre con
historial (§3), IFRA por sustancia (§5) y los datos en archivos del disco, no en la memoria
del navegador (§6).
